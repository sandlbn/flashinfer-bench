## Prerequisites

- OS: Linux
- Python: 3.10, 3.11, 3.12, 3.13
- An accelerator: NVIDIA (CUDA) or Intel (XPU). See [Hardware Support](/start/hardware-support)
  for backend selection, Intel install steps, and how kernel timing differs per backend.

## Python Package (WIP)

FlashInfer-Bench is available via pip:

```bash
python3 -m pip install flashinfer-bench
```

On NVIDIA hardware, add the `cuda` extra to get CUPTI-based kernel timing:

```bash
python3 -m pip install "flashinfer-bench[cuda]"
```

Without it, CUDA kernels are timed with device events instead, which include launch
overhead and are not comparable to CUPTI numbers.

## Install from Source

You may want to install FlashInfer-Bench from source code for development purposes.

```bash
# Clone the FlashInfer-Bench repository
git clone https://github.com/flashinfer-ai/flashinfer-bench.git

# Install the Python package
pip install -v -e .
```

## Verify installation

```python
>>> import flashinfer_bench as flb
>>> flb.__version__
'0.0.1'
```
